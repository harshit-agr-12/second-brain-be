# Second Brain (Backend)

Backend API for the Second Brain application — a personal knowledge & notes management system built with TypeScript and Node.js.

This service exposes RESTful endpoints to create, read, update, and delete user content (notes, memories, tasks, etc.) and supports modern features like authentication, validation, and structured storage. It’s designed to integrate with a corresponding frontend app to form a complete productivity system.

---

## 🚀 Features

- 🔐 **Authentication & Authorization**  
  User signup/login with secure password hashing (JWT based auth).

- 📄 **CRUD APIs for Notes & Memories**  
  Create, read, update, delete any knowledge items you store.

- 🗂️ **Tagging & Search Support**  
  Assign tags and filter/search items using flexible query parameters.

- ⛓️ **TypeScript-first Design**  
  Fully typed backend for better DX and fewer runtime bugs.

- 📦 **Modular Architecture**  
  Organized into controllers, services, models, and routes.

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Language | TypeScript |
| Runtime | Node.js |
| Server | Express.js |
| Database | MongoDB / PostgreSQL (configurable) |
| Auth | JWT (JSON Web Tokens) |
